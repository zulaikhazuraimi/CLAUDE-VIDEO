# Brand Nat Style Pack

1. On your computer, open the **Claude** app and click the **Code** tab.
2. Drag this whole folder (or the zip) into the chat.
3. Type: **install this skill for me**
4. Start a new chat and type: **show me the styles**

Pick your styles, copy the prompt, paste it in with your video. Done ✨

The first time you edit, Claude helps you set up two free video tools (about 5 minutes, only once).
